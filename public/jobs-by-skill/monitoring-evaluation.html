Frequently Asked Questions

Is monitoring and evaluation a common requirement?
It appears in the must-have skills of the listings shown above, so yes within this registry. Frequency varies by category.
Do I need a certificate?
Employers name the skill more often than a certificate. A portfolio or a project that uses the skill is usually stronger evidence.
How do I learn it?
Start with the tools named in the listings for your category, then build one small deliverable you can show.
